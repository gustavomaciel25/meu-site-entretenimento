
#  POP Station — Meu Portal de Entretenimento Digital

## Sobre o projeto

O POP Station é um portal de entretenimento digital desenvolvido como atividade da Agenda 13 do curso Técnico em Desenvolvimento de Sistemas.

A proposta foi criar uma página que reunisse alguns dos meus interesses nas áreas de filmes e séries, música e podcasts, games e tecnologia. O projeto foi inspirado na estética dos anos 2000, trazendo cores vibrantes e elementos visuais que remetem à cultura pop dessa época.

##  Objetivo

Desenvolver uma página utilizando HTML e CSS, colocando em prática os conhecimentos adquiridos durante as aulas, principalmente sobre estruturação de conteúdo, estilização de elementos e organização de layouts.

##  Tecnologias e recursos utilizados

- **HTML5:** utilizado para estruturar os conteúdos da página.
- **CSS3:** responsável pela aparência e organização visual.
- **Flexbox:** utilizado para organizar as três colunas principais do portal.
- **CSS Reset:** aplicado para padronizar a formatação inicial dos elementos.
- **CSS externo:** utilizado para concentrar os estilos no arquivo `estilo.css`.
- **CSS interno e inline:** utilizados para demonstrar diferentes formas de aplicação de estilos.

## Como visualizar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `portal.html`.
4. Abra o arquivo no navegador para visualizar a página.

##  Resultado

O resultado é uma página de entretenimento dividida em três categorias, reunindo referências de diferentes áreas da cultura pop em um único espaço.

Além da parte visual, o desenvolvimento permitiu praticar conceitos importantes de HTML e CSS, como a utilização de classes, identificadores, imagens, folhas de estilo e organização de elementos com Flexbox.
